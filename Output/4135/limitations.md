# 4135 Limitations

The current study has several limitations. They do not invalidate the
bounded positive result, but they define how the result should be read.

| limitation_id | limitation | implication |
| --- | --- | --- |
| L1 | The dataset is observational; no intervention was performed. | The analysis cannot establish individual-level causal forces. |
| L2 | The main cross-observation scope is 19 observations. | Heterogeneity associations are descriptive and small-n. |
| L3 | T1 is a focal-neighborhood aggregate residual. | It should not be equated with a single-insect behavioral rule. |
| L4 | `C,dCdt,R` is only one low-dimensional state representation. | Failure of this closure does not rule out all stochastic or state-dependent models. |
| L5 | The event-locality test used a state-matched near-pre aggregate. | It does not rule out other transition dynamics. |
| L6 | The confirmatory propagation route was not entered. | Propagation remains `NOT_TESTED`, not disproven. |
| L7 | History effects are observation-specific. | They do not support a universal memory or hysteresis mechanism. |
| L8 | Recording-condition metadata are not independently verified for causal use. | Daytime/dusk and observation-order explanations must remain annotations. |
| L9 | Figures 4134 are evidence-panel previews. | Final publication graphics still require format-specific redesign. |
| L10 | The 413x route is a synthesis route, not a new mechanism search. | New attractor, Langevin, propagation, or field/RG routes should be separate future branches. |
