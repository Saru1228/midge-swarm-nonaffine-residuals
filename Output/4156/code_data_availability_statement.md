# Code and Data Availability Statement

The trajectory data analyzed in this study are the published three-dimensional
time-resolved laboratory midge-swarm trajectories cited in the manuscript. The
raw trajectory files are treated as external data and are not bundled with the
generated analysis outputs in this workspace.

The analysis code, frozen configurations, provenance tables, final figures, and
manuscript artifacts are maintained in this project repository. For submission
or release, the repository should be archived with a persistent identifier. The
large generated tables can be regenerated from the published trajectories using
the archived scripts and configuration files.

The final manuscript package for this workspace is frozen under
`Output/4156/package/`. The package includes the compiled manuscript PDF, the
final manuscript entry file, the compilation log, the active LaTeX source chain,
the final figure PDFs, the bibliography file, the submission-facing supplement
draft, and the completed `B=1000` full-pipeline pseudo-event calibration
evidence from `Output/4155/`.
