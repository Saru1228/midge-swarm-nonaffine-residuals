\section*{Data and Code Availability}

The raw three-dimensional midge-swarm trajectories analysed in this study are
external data from the published dataset of Sinhuber et al.
\cite{sinhuber2019_dataset} and are not redistributed here. Analysis code,
frozen configurations, derived summary outputs, final manuscript artifacts,
and the completed high-replicate pseudo-event calibration are available at
\url{https://github.com/Saru1228/midge-swarm-nonaffine-residuals}, release tag
\texttt{v4158-review010-polish}. The repository includes a lightweight verification
script that checks the frozen manuscript package and the $B=1000$ omnibus-null
result without requiring access to the raw trajectories.
